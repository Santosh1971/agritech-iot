Program your ESP32 from the browser

Plug the ESP32 into your laptop with a USB data cable. Flash a ready program, or paste a program that Claude wrote for you, build it on our server and flash it. Nothing to install except the USB driver. Works in Google Chrome or Microsoft Edge on a laptop.

This browser can’t talk to USB devices. Open this page in Google Chrome or Microsoft Edge on a laptop (not on a phone, not Firefox or Safari).

Needed to build and flash.

Ready programs

Programs 1–3 need only the ESP32 DevKit: its blue LED (GPIO 2) and BOOT button (GPIO 0). The workshop kit adds: DHT22 → D23 · flow sensor → D35 (through the divider) · relay → D19 · clock (RTC) SDA → D21, SCL → D22. Programs 7–9 also work on a bare DevKit: the blue LED plays the pump.

Every program, the same 4 steps:
  1. Type the access code at the top (once).
  2. Click Choose on a program below.
  3. Click Flash to my ESP32 and pick the port (CP210x, CH340 or USB Serial). Wait for 100%.
  4. In the Serial monitor click Connect to see what the ESP32 is doing. Open How to use on the program card for what to try.

Program from Claude

  1. Copy a prompt below (it tells Claude about your board), change it to your idea, and paste it into claude.ai.
  2. Click Copy on Claude’s code and paste it below.
  3. Click Build (30–90 seconds), then Flash.
